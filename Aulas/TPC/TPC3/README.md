## Resumo

O objetivo deste trabalho é construir um analisador léxico para uma linguagem de query. A função `analyser` recebe o texto de entrada e devolve uma lista de tokens, cada um com o seu tipo, valor, linha e posição. Comentários e espaços são reconhecidos, contudo descartados.
